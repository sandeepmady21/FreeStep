# Superseded FreeStep Air concepts

**Historical reference only — not for fabrication, firmware deployment or human use.**
All contents in this directory predate the P0 simplification. Their dimensions,
prices, structural/clinical claims and software pass counts are unverified or
withdrawn. Multiple incompatible architectures are represented.

Original paths and relative links can be inspected in
[the original commit](https://github.com/sandeepmady21/FreeStep/tree/2715ab99605232bb07b756312aaa66696fbdf70c).
Some relative links within the archived snapshots no longer resolve after moving.
They are not current procurement instructions.

Old controller/tests/generators use `.reference.txt` extensions to prevent their
accidental use as the active build. Old browser viewers carry a superseded banner.
The archived STL plate generator omitted holes; do not order or print its structural
files. The original STEP model and images in the root remain original-project
references, not P0 assets.

Use the [current README](../../README.md),
[prototype specification](../../hardware/PROTOTYPE_SPEC.md) and
[research](../../research/CURRENT_PRODUCTS_AND_DESIGN.md) instead.
